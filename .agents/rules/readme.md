# README

- Keep `README.md` short and clean: what the project is, a table of contents, updates,
  reproduced algorithms, installation, and citation. Nothing else. Keep the table of
  contents in step with the `##` sections.
- Updates holds one dated line per user-facing milestone (`**[YYYY-MM-DD]**`, US Pacific
  time), newest first, such as a newly reproduced paper or a new feature.
- Reproduced Algorithms lists each reproduced paper, newest first, linked to its README
  under `reproduce/`, with no result numbers. Add a row when a new paper is reproduced.
- Do not edit the README unless necessary. Update it only when a user-facing change makes it
  wrong or incomplete (e.g. a new algorithm, model, dataset, or command). Never add
  implementation details, changelogs, or per-experiment notes.
- When updating, prefer editing an existing line over adding a new section.
